不止想停留在 AI 大模型问答上，而是去学 Agent 原理、项目和 Harness 工程——从何入手，看什么书，做什么项目。

## 核心认知：要学的是三层东西

1. **模型层**（可缓学）：LLM 怎么工作、token、上下文窗口、function calling 的消息协议
2. **Agent 原理**（核心）：Agent = 模型 + 工具 + 循环 + 反馈，本质是一个 `while` 循环——模型输出 → 执行工具 → 结果塞回上下文 → 再输出。ReAct 范式，仅此而已，没有魔法
3. **Harness 工程**（当前热点）：围绕模型搭的"驾驶舱"——工具定义与调度、上下文窗口管理（截断/压缩/摘要）、权限与沙箱、错误恢复、系统提示词设计、子代理编排、评测。Claude Code 本身就是一个顶级 Harness 的公开范例——**正在用它，就是最好的活教材**

## 按顺序读的东西（都免费/经典）

**第 1 步 · 地基（1 周）**

- Anthropic 博客 **《Building Effective Agents》**（2024-12）——最核心的一篇，讲清 workflow vs agent 的区别："从最简单的方案开始加复杂度"【https://www.anthropic.com/engineering/building-effective-agents】
- Lilian Weng 博客 **《LLM Powered Autonomous Agents》**（2023）——Agent 综述鼻祖，规划/记忆/工具三分法至今适用【https://lilianweng.github.io/posts/2023-06-23-agent/】
- OpenAI **《A Practical Guide to Building Agents》**（2025，免费 PDF）【https://assets.jimmysong.io/books/a-practical-guide-to-building-agents-zh.pdf】

**第 2 步 · 经典论文（2 周，只读这 5 篇）**

| 论文 | 学什么 |
|---|---|
| ReAct (2022) | 推理+行动交替的原始范式 |
| Toolformer / Function Calling | 模型怎么"调用"工具 |
| Reflexion | 失败后自我反思重试 |
| Voyager (2023) | 技能库 + 长期记忆的自主探索 |
| SWE-agent (2024) | 专讲 harness 设计：一个简单 harness 让模型修真实 GitHub issue，Harness 工程的开山之作 |

**第 3 步 · Harness 工程进阶（持续）**

- Anthropic 工程博客系列：**《Effective Context Engineering for AI Agents》**《Writing Effective Tools for AI Agents》《How we built Claude Code（多期）》——目前关于 harness 最体系的一手资料
- 成书首选：**Chip Huyen《AI Engineering》**（O'Reilly 2025，有中文版）——这波里最值得买的一本，Agent/评测章节很扎实；想深挖模型本身再补 Sebastian Raschka《Build a LLM From Scratch》
- 免费课程：**HuggingFace Agents Course**（huggingface.co/learn，有中文社区翻译），从 zero-agent 到多代理，带实操

## 项目路线：先裸写，再看框架，最后读源码

**阶段 1（最关键，别跳过）：用裸 API 手写一个 200 行的 CLI Agent**

- 不用任何框架，直接调 API：`while True` 循环 + 定义 3 个工具（读文件、写文件、执行 shell）
- 手动拼 tool_use / tool_result 的消息结构——做完这个就懂了一半的 harness
- 做完后加：工具执行失败的错误回传、单次工具需人工确认（权限系统雏形）、对话超过 N 轮后做摘要压缩（context 管理雏形）

**阶段 2：带着问题读真实开源 Harness 源码（由小到大）**

1. **smolagents**（HuggingFace）——最精简的可读 harness
2. **Aider**（Python）——专注 pair programming，工具设计极简
3. **SWE-agent**——学术论文配套的 harness，代码结构清晰
4. **OpenHands**（原 OpenDevin）——工业级全功能 harness
5. **Claude Code / Claude Agent SDK**——对照 Anthropic 博客看它的系统提示词设计、权限模型、子代理机制

读法：别通读，带着 3 个问题读——①工具是怎么定义和调度的 ②上下文满了怎么办 ③怎么防止模型干危险的事。

**阶段 3：做自己的项目并评测**

- 选一个真实场景（见姊妹篇[《影视内容生产管线》]({% post_url 2026-10-08-影视内容生产管线 %})——那条管线就是按"Workflow 为主，Agent 管异常"的 harness 架构设计的练手项目）
- 学 MCP（Model Context Protocol）接入外部工具
- 用 SWE-bench Verified / Terminal-Bench 的思路给自己出题，量化 agent 成功率——**评测能力是 harness 工程师和调 API 的玩家的分水岭**

## 8 周节奏

| 周 | 内容 | 产出检验 |
|---|---|---|
| 1 | 地基博客 + HF Agents Course 前半 | 能说清 workflow vs agent |
| 2 | 裸写 CLI Agent v1 | 200 行代码跑通工具循环 |
| 3 | 5 篇论文 + 补 context 管理 | Agent v2：带压缩和权限确认 |
| 4-5 | Anthropic 工程博客 + smolagents 源码 | 一篇源码分析笔记 |
| 6-7 | OpenHands 或 SWE-agent 源码 + MCP | 接一个自定义 MCP 工具 |
| 8 | 自己的项目 + 简单评测 | 量化成功率，写总结博客 |

## 大坑提醒

**不要从 LangChain/CrewAI 入门。** 框架会把你和真实机制隔开，而且这些框架的抽象和真实 harness 的关注点（上下文、权限、评测）偏差不小。先裸写，再用框架，才能分辨哪些抽象有价值。

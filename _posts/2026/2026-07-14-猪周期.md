# Layer 1：领先层（预测未来 6–12 个月）

## 📊 指标 1.1 · 能繁母猪存栏 YoY

### 定义
全国能繁母猪存栏量的同比变化率（年化%）。

### 为什么重要
**这是猪周期最本质的领先指标**。因为：
- 母猪 → 仔猪需要 4 个月
- 仔猪 → 出栏需要 6 个月
- 所以母猪存栏**领先猪价约 10 个月**

**YoY 直接告诉你未来 10 个月的供给方向**。

### 数据源
- **官方**：农业农村部畜牧兽医局月报（每月中旬发布**上上个月**数据，滞后 45 天）
- **公开渠道**：
  - 农业农村部官网 → 数据 → 畜禽生产
  - 中国政府网新闻发布会通稿
  - 涌益咨询 / 卓创资讯（付费但更及时）
- **免费替代**：国家统计局季度数据（滞后更长，但可校准）

### 打分规则（历史分位数版）
**取过去 10 年（2016-至今）该指标的历史分位**：

| YoY 值 | 历史分位 | 打分 |
|---|---|---|
| < -10% | 最低 5% | **+2.0** |
| -10% ~ -5% | 最低 5-15% | **+1.5** |
| -5% ~ -2% | 最低 15-30% | **+1.0** |
| -2% ~ +2% | 中间 30-70% | **0** |
| +2% ~ +5% | 最高 30-15% | **-1.0** |
| +5% ~ +10% | 最高 15-5% | **-1.5** |
| > +10% | 最高 5% | **-2.0** |

### 历史值范围

```
2018-08 非洲猪瘟前:  YoY  +2%   (中性)
2019-09 猪瘟去化谷底: YoY -38%   ★★★极端信号 (+2)
2020-11 补栏顶峰:    YoY +31%   ★★★极端信号 (-2)
2022-04 22年周期底:  YoY  -8%   (+1.5)
2024-04 上一次去化底:YoY  -5%   (+1)
2026-05 当前估计:    YoY  -3%   (+1) ← 你现在的位置
```

### 失效场景
- ❌ **突发疫情**（非洲猪瘟级别）导致强制淘汰 → 短期 YoY 剧烈失真，需要人工降权
- ❌ **政策强制干预**（如"环保关停"或"临时收储"）→ 母猪数据受政策扭曲
- ❌ **数据修订**：农业部经常回溯修订历史数据，需要跟踪

## 📊 指标 1.2 · 能繁母猪存栏 环比 & 加速度

### 定义
- **环比**：当月 vs 上月存栏变化率
- **加速度**：环比变化率的月度变化（二阶导）

### 为什么重要
**YoY 反应慢，环比+加速度更敏感**。当周期转向时：
- YoY 从 -8% → -6% 只是"看似回暖"
- 环比连续 3 个月正增长 → **真正的拐点已经发生**
- 环比加速度由负转正 → **拐点信号最早出现**

**加速度信号往往比 YoY 提前 3–6 个月**。

### 数据源
同 1.1（农业农村部月报），自己算环比。

### 打分规则（组合信号）

**方向性打分**：
| 环比 | 打分 |
|---|---|
| < -2% | +1.0 |
| -2% ~ -0.5% | +0.5 |
| -0.5% ~ +0.5% | 0 |
| +0.5% ~ +2% | -0.5 |
| > +2% | -1.0 |

**加速度打分**（连续 3 个月方向）：
| 连续 3 个月环比方向 | 加成 |
|---|---|
| 连续 3 月负增且加速下降 | **+1.0** |
| 连续 3 月正增且加速上升 | **-1.0** |
| 反转（负→正 或 正→负） | ⚠️ 拐点警示（另外标红提示，不加分） |

**最终得分 = 方向性 + 加速度**（范围 -2 ~ +2）

### 历史值范围

```
2019-01 至 2019-09: 连续9月负增，最大月度-4.8% → 满分 +2
2020-04 起: 连续正增，最大 +3.6%             → 满分 -2
2022-01 至 2022-04: 连续负增，月均-1.2%       → +1.5
2024-Q1: 环比 -0.4% 微跌                     → +0.5
2026-04 至今: 环比连续负 3 月，加速度转负     → +1.5 (估计)
```

### 失效场景
- ❌ **季节性因素**：春节前后母猪数据自然波动 → 需要用同期比较，或做季调
- ❌ **数据修订**：环比对修订最敏感，滞后修订常导致信号反复
- ❌ **统计口径变化**：2018 年农业部曾变过"能繁母猪"定义，历史数据不完全可比

## 📊 指标 1.3 · 15 公斤仔猪价格

### 定义
15 公斤外三元仔猪的全国均价（元/公斤 或 元/头）。

### 为什么重要
**养殖户"用真金白银投票"的指标**。核心逻辑：
- 仔猪买入 → 4-6 个月后出栏
- 如果养殖户愿意花 40 元/公斤 买仔猪（历史高位），说明**他们赌 6 个月后猪价会大涨**
- **仔猪价领先出栏猪价约 4–6 个月**

**关键背离信号**：
- **猪价跌 + 仔猪涨** → 底部信号（散户开始重新入场）
- **猪价涨 + 仔猪跌** → 顶部信号（养殖户不再补栏）

### 数据源
- 农业农村部 500 个农村集贸市场监测（周度公布）
- 涌益咨询 / 卓创资讯（付费，日频）
- **免费**：农业农村部官网 → 畜牧产品价格 → 仔猪价格

### 打分规则（水平 + 背离）

**A. 水平打分**（历史分位）：
| 仔猪价 (元/kg) | 历史分位 | 打分 |
|---|---|---|
| < 20 | 最低 10% | +1.5 |
| 20-25 | 最低 30% | +0.5 |
| 25-35 | 中间 | 0 |
| 35-45 | 最高 30% | -0.5 |
| > 45 | 最高 10% | -1.5 |

**B. 背离信号加成**：
| 情形 | 加成 |
|---|---|
| 猪价 6 月移动均线跌 + 仔猪 3 月移动均线涨 | **+1.0** ⭐ 强底部 |
| 猪价 6 月移动均线涨 + 仔猪 3 月移动均线跌 | **-1.0** ⭐ 强顶部 |

### 历史值范围

```
2019-06 猪瘟去化尾声: 仔猪 22元/kg (低位)
2020-08 补栏疯狂:    仔猪 105元/kg ★极端顶部 (-1.5)
2022-04 上轮周期底:  仔猪 27元/kg (+0.5) + 背离信号 (+1)
2024-Q1:            仔猪 30元/kg (0)
2026-05 估计:        仔猪 20元/kg (+1.5) + 是否背离待验证
```

### 失效场景
- ❌ **疫病期**：非洲猪瘟期间仔猪价格因跨省调运受限严重扭曲
- ❌ **头部公司自繁自养**：牧原 100% 自繁，不参与仔猪市场；仔猪价越来越只反映散户情绪
- ⚠️ **注意**：随着规模化养殖占比提升，仔猪价的领先意义**正在减弱**（这是长期风险）

## 📊 指标 1.4 · 能繁母猪 vs 正常保有量

### 定义
当前能繁母猪存栏量 与 农业农村部公布的**正常保有量 3900 万头**（2024 版）的偏离度。

### 为什么重要
**这是政策信号，不是市场信号**。
- 农业部会公布"绿色区间/黄色预警/红色预警"
- 跌破红色区间 → **触发政策调控**（收储、补贴、限制进口）
- 政策底往往比市场底更硬

### 数据源
- 农业农村部《生猪产能调控实施方案》官方文本
- 部级例行新闻发布会（月度）
- **免费**：农业农村部官网 → 政策法规

### 打分规则

**2024 版调控目标**：
- 正常区间：3700-4000 万头
- 黄色预警：3500-3700 万头
- 红色预警：< 3500 万头
- 蓝色预警（过剩）：> 4100 万头
| 存栏水平 | 政策信号 | 打分 |
|---|---|---|
| < 3500 万头 | 红色预警 → 强调控 | **+2.0** |
| 3500-3700 | 黄色预警 | **+1.0** |
| 3700-4000 | 正常 | 0 |
| 4000-4100 | 接近上限 | -0.5 |
| > 4100 | 蓝色预警（过剩） | **-2.0** |

### 历史值范围

```
2019-09: 1913 万头 (远低红线) 满分 +2
2021-06: 4564 万头 (蓝色预警) 满分 -2
2024-04: 3986 万头 (正常偏下) 0.5
2026-05 估计: ~3900 万头 (正常) 0

但注意: 政策目标本身在 2024 从 4100 下调到 3900
       所以"合理值"也在变
```

### 失效场景
- ❌ **政策目标调整**：农业部会不定期调整正常保有量数字（2019=4100 / 2022=4100 / 2024=3900），每次调整都要**重设阈值**
- ❌ **政策执行力度**：公布预警不等于真正调控，要看后续实际动作

# Layer 2：同步层（确认当下）

## 📊 指标 2.1 · 全国生猪均价 vs 成本线

### 定义
全国外三元生猪出栏均价 与 **行业平均完全成本** 的差值（元/公斤）。

### 为什么重要
**猪价本身没意义，猪价 vs 成本才有意义**。
- 2020 年成本 12 元/kg，猪价 30 元 → 暴利
- 2024- 2024 年成本 15 元/kg，猪价 15 元 → 平本
- 2026 年成本 14 元/kg，猪价 10 元 → 深亏 4 元/kg

**盈亏差比猪价本身更能反映周期位置**。

### 数据源
- **猪价**：
  - akshare `futures_pig_info`（免费，日频）
  - 农业农村部 500 集贸市场（周频）
  - 涌益/卓创（付费，最准）
- **成本线**（这是难点，需要估算）：
  - 涌益咨询"自繁自养头均利润"倒推
  - 上市公司季报（牧原、温氏成本披露）
  - 大致规律：**行业成本 = 玉米现货价 × 3.5 + 豆粕 × 1.2 + 其他 ≈ 13-15 元/kg**

### 打分规则

**猪价 vs 成本 差值（元/kg）**：
| 差值 | 状态 | 打分 |
|---|---|---|
| < -3 | 全行业深度亏损 | **+2.0** |
| -3 ~ -1 | 深亏 | +1.5 |
| -1 ~ 0 | 微亏 | +0.5 |
| 0 ~ +2 | 微利 | 0 |
| +2 ~ +5 | 良好 | -0.5 |
| +5 ~ +10 | 高盈利 | -1.5 |
| > +10 | 暴利 | **-2.0** |

### 历史值范围

```
2019-10 猪瘟顶: 猪价 40 - 成本 15 = +25    满分 -2 (顶部)
2020 全年:     猪价 34 - 成本 15 = +19    -2 (顶部延续)
2021-10 崩盘: 猪价 12 - 成本 17 = -5     满分 +2 (深亏)
2022-04 底部: 猪价 12 - 成本 17 = -5     +2
2024-Q1:      猪价 15 - 成本 15 = 0      0
2026-05:      猪价 10 - 成本 14 = -4     +2 (你现在的位置)
```

### 失效场景
- ❌ **头部 vs 行业成本差距大**：牧原成本 12.5 元，行业 14.5 元。行业深亏时牧原还小赚，用行业成本会低估牧原的护城河
- ❌ **饲料价格剧烈波动**：玉米/豆粕暴涨时，成本线快速上移，历史阈值失效
- ⚠️ **成本线估算误差**：这是本框架**最难精确的一个变量**，建议每季度重新校准一次

## 📊 指标 2.2 · 头均盈亏（自繁自养）

### 定义
养殖一头猪从出生到出栏的全流程头均利润（元/头）。

### 为什么重要
- 猪价 vs 成本是**元/kg 视角**
- 头均盈亏是**元/头视角**
- 两者互相验证，防止单一指标失真

**头均盈亏 -300 元 是行业公认的"深度亏损线"**。

### 数据源
- **涌益咨询周报**（免费摘要，付费全文）
- **卓创资讯**（付费）
- **免费替代**：自行计算 = (猪价 - 成本价) × 出栏均重（约 120 公斤）

### 打分规则

| 头均盈亏（元/头） | 状态 | 打分 |
|---|---|---|
| < -400 | 极端深亏（历史罕见） | **+2.0** |
| -400 ~ -200 | 深度亏损 | +1.5 |
| -200 ~ -50 | 亏损 | +1.0 |
| -50 ~ +100 | 平本 | 0 |
| +100 ~ +500 | 盈利 | -0.5 |
| +500 ~ +1500 | 高盈利 | -1.5 |
| > +1500 | 暴利（历史罕见） | **-2.0** |

### 历史值范围

```
2019-10 猪瘟顶: 头均盈利 +3000 元 ★★极端 (-2)
2020 全年:     头均盈利 +2000 元 (-2)
2021-10 崩盘: 头均盈亏 -600 元 ★极端 (+2)
2022-04 底部: 头均盈亏 -400 元 (+1.5)
2024-Q3 短反弹:头均盈利 +300 元 (-0.5)
2026-05 当前: 头均盈亏 -280 元 (+1.5, 你现在的位置)
```

### 失效场景
- ❌ **数据滞后 & 口径差异**：不同机构（涌益/卓创/上市公司）披露的头均盈亏差距可达 100 元
- ❌ **自繁 vs 外购分化**：外购仔猪养殖模式在仔猪高价期头均盈亏比自繁自养差 300 元+，需要区分
- ⚠️ **建议只跟踪"自繁自养"口径**（更代表规模化企业）

## 📊 指标 2.3 · 猪粮比

### 定义
生猪出栏均价 ÷ 玉米现货均价。

### 为什么重要
**这是国家发改委官方使用的调控指标**，硬性政策阈值：
- **< 5:1** → 触发国家收储（政策底）
- **> 9:1** → 触发国家投放储备肉（政策顶）
- **5-9** 为正常区间

**猪粮比是唯一有明确"政策阈值"的指标**，具有硬约束意义。

### 数据源
- 国家发改委价格监测中心 **每周三公布**
- **免费**：发改委官网 / 猪易网 / 中国养猪网
- akshare 未直接提供，需从发改委抓取

### 打分规则

| 猪粮比 | 政策信号 | 打分 |
|---|---|---|
| < 4.5 | 严重亏损 → 强收储 | **+2.0** |
| 4.5 - 5.0 | 触发收储线 | +1.5 |
| 5.0 - 5.5 | 亏损区 | +1.0 |
| 5.5 - 7.0 | 微利/正常 | 0 |
| 7.0 - 8.5 | 良好盈利 | -0.5 |
| 8.5 - 10.0 | 高盈利 | -1.5 |
| > 10.0 | 触发投放 | **-2.0** |

### 历史值范围

```
2019-10: 猪粮比 20+ (历史极端顶) 满分 -2
2020: 猪粮比 12-16                -2
2021-10: 猪粮比 4.3               +2
2022-04: 猪粮比 4.9               +1.5
2024-Q3: 猪粮比 8.5 (小顶)         -0.5
2026-05: 猪粮比 4.8 (估计)         +1.5 (你现在的位置)
```

### 失效场景
- ❌ **饲料结构变化**：现代规模化养殖中，玉米占饲料 60%，豆粕 15%。**猪粮比对豆粕暴涨不敏感**
- ❌ **政策调控软化**：近年来收储量减少，"政策底"越来越像"心理底"而非"实际底"
- ⚠️ **注意**：猪粮比是**历史沿用指标**，越来越不能反映真实盈亏，只保留其"政策触发"意义

# Layer 3：滞后层（验证行业反应）

## 📊 指标 3.1 · 上市公司季度亏损家数占比

### 定义
A 股生猪养殖上市公司（约 8 家：牧原、温氏、新希望、正邦、天邦、大北农、罗牛山、傲农）中，**单季度归母净利润为负**的家数占比。

### 为什么重要
- **官方财报证明的行业困境**，比任何调研都可信
- **底部构筑的标志性信号**：当 6/8+ 家亏损，说明**行业压力已到临界点**
- 这类"共同亏损"往往是产能出清的前奏

### 数据源
- akshare `stock_report_disclosure`（季报披露表）
- 各公司季报（4月/8月/10月）
- **免费且自动化程度最高的指标之一**

### 打分规则

| 亏损家数占比 | 打分 |
|---|---|
| ≥ 75% (6/8+) | **+2.0** |
| 62.5% (5/8) | +1.5 |
| 50% (4/8) | +1.0 |
| 37.5% (3/8) | 0 |
| 25% (2/8) | -0.5 |
| 12.5% (1/8) | -1.0 |
| 0% (全盈利) | **-2.0** |

### 历史值范围

```
2019 Q1-Q4:    2/8 - 3/8 亏损 (混沌区)
2020 全年:     0-1/8 (全行业暴利, -2)
2021 Q3-Q4:   5/8 - 7/8 亏损 (+1.5 到 +2)
2022 Q1:      6/8 亏损 (+2, 底部)
2023 Q1-Q3:   5/8 - 6/8 亏损 (行业困境延长)
2024 Q1:      5/8 亏损 (+1.5)
2024 Q3-Q4:   1-2/8 亏损 (小顶部)
2026 Q1:      5/8 - 6/8 亏损 (+1.5, 估计, 你现在的位置)
```

### 失效场景
- ❌ **样本量小**：8 家公司，一家出问题就影响一档。ST/退市公司的样本变化要人工调整
- ❌ **季度周期性**：Q1 通常因春节备货、饲料涨价而亏损面偏大，需要跟同期比较
- ⚠️ **数据滞后 1-2 个月**：季报披露完之后才能算，反应慢

## 📊 指标 3.2 · 头部公司资本开支 & 在建工程

### 定义
牧原、温氏、新希望三家头部公司**在建工程金额** 与 **资本开支增速**。

### 为什么重要
**这是纯粹的"产能扩张 vs 收缩"信号**：
- 在建工程飙升 → 产能扩张 → **未来利空**
- 在建工程骤降 → 产能收缩 → **行业出清中**
- **企业停止扩张 = 认输 = 周期底部信号**

历史规律：在建工程见顶后 12-18 个月，猪价见底。

### 数据源
- 上市公司季报 `合并资产负债表 → 在建工程`
- akshare `stock_balance_sheet_by_report_em`
- 三家头部公司数据自行汇总

### 打分规则

**A. 在建工程 YoY 变化**：
| 三家合计在建工程 YoY | 打分 |
|---|---|
| < -30% | +2.0 (产能大幅收缩) |
| -30% ~ -10% | +1.0 |
| -10% ~ +10% | 0 |
| +10% ~ +30% | -1.0 |
| > +30% | -2.0 (疯狂扩张) |

**B. 资本开支 vs 折旧摊销比**（辅助信号）：
| Capex / D&A | 状态 | 加成 |
|---|---|---|
| < 0.8 | 维护性 capex，行业停止扩张 | +0.5 |
| 0.8 - 1.5 | 正常 | 0 |
| > 2.0 | 疯狂扩张 | -0.5 |

**合并得分**：范围 -2.5 ~ +2.5，超过 ±2 按 ±2 计。

### 历史值范围

```
2020 全年:  三家在建工程 YoY +180%,  Capex/D&A ~ 4x  → -2 (疯狂扩张)
2021 Q4:    在建工程 YoY 见顶回落                    → -1
2022 Q4:    在建工程 YoY -12%, Capex/D&A ~ 1.2      → +1
2024 Q4:    在建工程 YoY -25%, Capex/D&A ~ 0.9      → +1.5 (产能出清中)
2026 Q1估计: 在建工程 YoY -20%, Capex/D&A ~ 0.7     → +1.5 (你现在)
```

### 失效场景
- ❌ **头部公司战略分化**：牧原持续扩张 vs 新希望大幅收缩，加总会掩盖信号
- ❌ **在建工程转固定资产**：单季度可能因大项目转固而"骤降"，这不是真收缩，是完工
- ⚠️ **建议**：既看在建工程绝对值，也看 Capex/D&A 比率，交叉验证

## 📊 指标 3.3 · 头部公司月度出栏加速度

### 定义
牧原、温氏、新希望三家头部公司**月度出栏量 YoY** 与 **环比加速度**。

### 为什么重要
- **供给侧的实时数据**（比农业部滞后数据快 15-20 天）
- 头部占全国出栏 15%+，其加速出栏 = 短期供应压力
- **关键信号**：**头部出栏见顶 → 供给冲击释放完毕 → 猪价见底**
### 数据源
- 三家公司**月度经营简报**（每月 5-10 号发布）
- akshare `stock_notice_report`
- 免费且更新及时

### 打分规则

**A. 三家合计出栏 YoY**：
| YoY | 状态 | 打分 |
|---|---|---|
| > +40% | 供应放量，价格承压 | **-1.5** |
| +20% ~ +40% | 增长 | -0.5 |
| 0% ~ +20% | 常态 | 0 |
| -20% ~ 0% | 温和收缩 | +0.5 |
| < -20% | 大幅收缩 | **+1.5** |

**B. 环比加速度**（辅助）：
| 环比 3 月方向 | 加成 |
|---|---|
| 连续 3 月加速上升 | -0.5 |
| 连续 3 月加速下降 | +0.5 |

**合并得分**：范围 -2 ~ +2。

### 历史值范围

```
2020-2021:  三家合计出栏 YoY +50% 至 +80% (-1.5, 供应冲击)
2022-04:    出栏 YoY +25% (但价格已崩，说明底部临近)
2024-Q1:    出栏 YoY +12% (0)
2026-Q1-Q2: 出栏 YoY +15%, 但增速放缓 → 0 (中性偏空)
```

### 失效场景
- ❌ **头部集中度提升的结构性问题**：全国出栏在跌，但头部在涨，因为在**吃小散户的份额**。这不是周期上行信号
- ❌ **压栏/抛售扰动**：养殖户预期变化会导致月度出栏节奏严重扭曲
- ⚠️ **建议**：**同时看总量 和 三家占全国出栏比例**（比例上升说明是"结构挤压"，不是"周期需求"）

# 🎲 打分聚合规则

## 每层加总

```
Layer 1 领先层：4 个指标，每个 -2 ~ +2，合计 -8 ~ +8
Layer 2 同步层：3 个指标，每个 -2 ~ +2，合计 -6 ~ +6
Layer 3 滞后层：3 个指标，每个 -2 ~ +2，合计 -6 ~ +6
```

## 综合得分

**方案 A（简单加总）**：三层直接加，范围 -20 ~ +20

**方案 B（推荐 · 层级加权）**：不是给指标加权，而是给层级加权，突出领先层：

```
综合得分 = Layer1 × 1.2 + Layer2 × 1.0 + Layer3 × 0.8
```

范围仍是约 -20 ~ +20，但**领先层的信号被适度放大**，因为它对未来更重要。

## 状态判定 & 动作矩阵

| 综合得分 | 周期状态 | 建议仓位 | 情绪要求 |
|---|---|---|---|
| **+14 ~ +20** | 极度深度底部 | 满仓 + 加杠杆 | 极度贪婪 |
| **+8 ~ +13** | 深度底部构筑 | 60-80% 仓位 | 冷静布局 |
| **+3 ~ +7** | 底部区 | 30-50% 仓位 | 分批建仓 |
| **-2 ~ +2** | 中场混沌 | 20-30% 仓位 | 持有观望 |
| **-7 ~ -3** | 上升中段 | 减仓中 | 警惕高估 |
| **-13 ~ -8** | 顶部构筑 | 10-20% 仓位 | 分批止盈 |
| **-20 ~ -14** | 极度顶部 | 清仓 + 反向 | 极度恐惧 |

## 冲突提示规则

不只看总分，还要**显式展示冲突**：

```python
if Layer1_score >= 6 and Layer3_score <= 0:
    提示 = "领先层强底部信号，但滞后层未跟上 → 底部构筑早期，可开始分批"

if Layer1_score <= -6 and Layer2_score >= 3:
    提示 = "领先层已转熊，但同步层仍强 → 顶部尚未确认，可继续持有但设置止盈"

if abs(Layer1_score + Layer2_score + Layer3_score) < 3 and 各层内部方差大:
    提示 = "各层信号分歧严重 → 周期正在转向，观望"
```

# 🧪 历史回测检查项

在你真正用这个框架前，**必须回测过去 4 轮周期**：

## 检查项 1：**顶底得分对称性**
- 2019-10 顶部得分应该在 -14 以下
- 2022-04 底部得分应该在 +14 以上
- 如果不对称（比如底部只有 +8），说明**框架偏乐观或偏悲观**，需要调整阈值

## 检查项 2：**信号提前量**
- 领先层信号是否提前**猪价拐点 6-10 个月**？
- 如果提前量不足 3 个月，说明**没有"领先"意义**，需要调整指标

## 检查项 3：**假信号率**
- 是否出现过 **得分 > +10 但后续 6 个月股价继续跌 20%+** 的情况？
- 如果有 2 次以上，说明**框架无法区分"底部构筑期"和"真正底部"**，需要加入"结构确认"信号

## 检查项 4：**参数稳定性**
- 用 2010-2018 数据校准的阈值，套到 2018-2026 是否失效？
- 如果失效严重，说明**阈值过拟合**，需要用滚动窗口分位数

# 🎯 最后：把这套框架变成"你的东西"

上面 10 个指标是**通用起点**，但要成为**你的**看板，还要做三件事：

**① 挑掉不合你脾气的指标**
比如你如果坚决不看付费数据源，那 2.2 头均盈亏就要用**你自己算的估算值**替代，或者直接删掉。**留下的指标必须是你 100% 能定期更新的**。

**② 给每个指标写"我看到 X 就该做 Y" 的一句话规则**
不是抽象打分，而是操作指令。比如：
> "当 1.1 打分 ≥ +1.5 且 1.2 打分 ≥ +1，我承诺：**7 个交易日内启动首笔加仓，不再犹豫。**"

**③ 每季度做一次"框架健康度体检"**
- 上季度信号准不准？
- 有没有指标反复给假信号？该删还是改阈值？
- 有没有新变量应该加进来？（比如新增的政策、新技术）
